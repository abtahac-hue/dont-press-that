# Main dependencies

This repository includes application source and dependency manifests, not vendored dependency code. Installed packages retain their own licenses.

- React: https://github.com/facebook/react
- Vinext: https://github.com/cloudflare/vinext
- Vite: https://github.com/vitejs/vite
- Cloudflare Vite plugin and Wrangler: https://github.com/cloudflare/workers-sdk
- Drizzle ORM / Drizzle Kit: https://github.com/drizzle-team/drizzle-orm
- Lucide icons: https://github.com/lucide-icons/lucide
- Tailwind CSS: https://github.com/tailwindlabs/tailwindcss
- TypeScript: https://github.com/microsoft/TypeScript

The lockfile preserves the original starter's dependency graph, including packages not currently imported by this game's screens. Review dependency licenses before redistribution.
